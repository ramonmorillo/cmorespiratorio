# Guía rápida — SIAF-CMO Respiratorio

Herramienta de apoyo. No sustituye el juicio clínico. Use solo identificadores seudonimizados.

## Valoración completa (5–8 minutos)

1. **Inicio:** escriba hospital, farmacéutico/a y un código seudonimizado (nunca nombre, NHC, DNI ni CIP). Elija:
   - **Comenzar manualmente**, o
   - **Analizar texto clínico:** pegue texto seudonimizado y pulse *Analizar localmente*. Revise cada propuesta: *Confirmar dato* o *Descartar*. Las menciones dudosas no se preseleccionan. El texto pegado se borra tras el análisis.
2. **Historia clínica:** marque las patologías y elija la principal. Escriba edad e IMC (se aplican automáticamente). Responda cada variable *Sí/No*. Las tarjetas en amarillo están pendientes.
3. **Revisión:** compruebe la tabla de respuestas y puntos.
4. **Estratificación:** verá puntuación (/59), prioridad y excepciones. Si hay pendientes, la aplicación indica hasta dónde podría subir la prioridad. Puede modificar la prioridad por criterio profesional, pero solo se aplica con justificación (≥12 caracteres). Pulse **Validar y finalizar** (si faltan datos: completar o *Finalizar como provisional*).
5. **Necesidades:** factores que han puntuado, por dimensión; los de tratamiento son las necesidades farmacoterapéuticas.
6. **Intervenciones:** para cada actuación del nivel, indique *Realizada*, *Planificada / pendiente* o *No procede* (por defecto: *Recomendada por el modelo*). Añada fecha de próxima valoración y observaciones.
7. **Informe:** **Copiar informe para historia clínica** (aparece confirmación; si el navegador lo impide, el texto queda seleccionado: pulse Ctrl+C) o **Descargar PDF**.

## Interpretación

- **P1** ≥32 puntos o excepción (embarazo/puerperio; <18 años en consulta de adultos). **P2** 21–31. **P3** ≤20.
- Las actuaciones son acumulativas: P2 incluye P3; P1 incluye P2 y P3.
- **Provisional** = existen variables pendientes (puntúan 0 hasta valorarlas).
- **Edad pediátrica** (0–15 fuera de consulta de adultos): el modelo no aplica; derive al modelo pediátrico.

## Buenas prácticas

- Si cambia un dato tras finalizar, los informes se bloquean hasta *Validar y finalizar* de nuevo.
- *Nueva evaluación* limpia la pantalla para el siguiente paciente.
- Los casos se guardan solo en este navegador. En equipos compartidos, use *Borrar todos los casos* al terminar.
- Revise siempre el texto pegado en la historia clínica antes de guardarlo.
